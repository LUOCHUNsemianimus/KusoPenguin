# Maid Melee Kick Compat / 女仆近战飞踢兼容

中文：本兼容只对实际 `touhou_little_maid:maid` 且任务 UID 精确为 `touhou_little_maid:attack` 的女仆开放共享 `PenguinKick`。候选项必须有存活当前目标，并通过 `canAttack`、盟友、坐姿、骑乘检查；无目标、远程、农场、待机、主人/盟友均不触发。女仆复用同一服务端 Flight、碰撞/横扫/速度缩放/冷却，基础距离 4 格、高度 1 格，再乘已有移动速度缩放；命中仍由女仆原生 `doHurtTarget` 动态覆盖处理，因此 Pre/Post、饰品、武器耐久、原版横扫、附魔与伤害计算不变。女仆处于本模组飞踢期间，可选 mixin 在 `EntityMaid.doHurtTarget` HEAD 拦截普通覆盖，只有本次共享踢的 `MOB_STRIKE` 调度可通过。没有 TLM 时 facade 和 `@Pseudo` mixin 均惰性跳过。

English: This optional bridge admits only an actual `touhou_little_maid:maid` whose task UID is exactly `touhou_little_maid:attack`. The maid must be alive, have a live current target, and pass `canAttack`, ally, sitting and passenger checks; no-target, ranged, farm, idle, owner and ally cases are excluded. It reuses the one server `PenguinKick` Flight, collision/sweep/speed-scale/cooldown path, with player-like 4-block distance and 1-block height before the existing movement-speed scale. Hits still dispatch through the maid's native dynamic `doHurtTarget` override, preserving Pre/Post events, baubles, weapon durability, native sweep, enchantment and damage calculation. While an eligible maid is in a kick, the optional mixin cancels ordinary calls at `EntityMaid.doHurtTarget` HEAD; only the shared kick's `MOB_STRIKE` dispatch is allowed. Both the facade and the `@Pseudo` mixin are skipped lazily when TLM is absent.

## Physical contact for ordinary penguin-maid melee / 普通近战接触限制

Cause: TLM `EntityMaid.isWithinMeleeAttackRange` compares `distanceTo(target)` with `ENTITY_INTERACTION_RANGE + favorabilityBonus` (base 2, favorability bonus 0/1/3/5), which can pass at roughly four or more center-distance blocks even when the boxes are far apart. `MaidMeleeAttack` swings and starts its attack cooldown on that result before `doHurtTarget`, so the visible 4-block damage is native AI intent, not the kick's launch distance. The `2..4.5` chooser distance is only kick launch selection; the kick itself hits through its bounded per-step swept box.

Behavior: For a penguin-effect maid only, two HEAD gates share `MaidKickCompat.hasContact`: `isWithinMeleeAttackRange` returns `maid.getBoundingBox().inflate(.35,.15,.35).intersects(target.getBoundingBox())`, so the native AI does not swing or start cooldown at the old range. `doHurtTarget` cancels non-contact ordinary calls before TLM Pre/baubles; the shared kick's `PenguinKick.dispatching(Mob)` MOB_STRIKE path is explicitly distinguished and keeps the native TLM damage chain. The mob sweep is additionally limited to the approved per-step displacement (`maxStepSqr`), so no teleport/external displacement can become a four-block ghost-hit corridor. Non-penguin maids retain TLM behavior. No TLM damage, enchantment, sweep or weapon logic is copied.
