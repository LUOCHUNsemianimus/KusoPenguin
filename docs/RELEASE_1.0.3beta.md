# Kuso Penguin 1.0.3beta 更新说明

适用 **Minecraft 1.21.1 / NeoForge 21.1.243（同 21.1.x 兼容版本）/ Java 21**。本版本沿用舞蹈网络协议 3，客户端与服务端必须同时更新到同一构建，否则会被拒绝连接。

## 女仆乐器舞蹈的全局作息策略

- 新增全局服务端开关 `unrestrictedMaidMusicDance`，位于游戏/服务端工作目录下的 `config/kuso_penguin-server.toml` 的 `[dance]` 段，**默认 `false`**。该配置仍为 SERVER 类型，对当前服务器全局生效，不是每玩家设置。
- `false` 时，女仆要加入女仆乐器舞蹈，必须同时满足：精确类型 `touhou_little_maid:maid`；当前任务为待命 `touhou_little_maid:idle`；原生 `getScheduleDetail()` 为 `Activity.IDLE`（即中文界面的“休息”）。任务为空或日程不可用时不加入。
- `true` 时恢复此前不限任务与作息的行为，其余范围、MIDI、优先级和所有权门禁不变。
- 获取女仆音乐舞蹈来源与每 tick 复核共用同一个资格判断。关闭开关、切换任务或作息离开休息时，只立即移除 `MAID_MUSIC` 来源；若没有其他来源则释放舞蹈 AI，玩家手动舞蹈、复活和唱片机规则不受影响。
- 管理员命令：`/kusopenguin maidmusic` 显示当前状态，`/kusopenguin maidmusic <true|false>` 切换并保存到上述现有配置；整个 `maidmusic` 子命令要求权限等级 2。单人存档的 OP 可即时切换。

## 自上次公开发布以来已审核的变更

- **Yes Steve Model 2.6.5 玩家兼容**：实际玩家保留 YSM 原生头/头发，身体替换为共享企鹅体；主副手、滑翔和原生层按快照回放。固定的 2.6.5 为可选依赖；玩家路径不要求安装女仆模组，缺少 YSM 或契约不满足时回退原生渲染。
- **两个管理快捷键默认未绑定**：“打开自定义唱片库”和“打开舞蹈管理”；命令入口仍为 `/kusopenguin disc` 与 `/kusopenguin dances`，不要求企鹅效果，也不占用八个舞蹈轮盘槽位。
- **上传与槽位配额**：每玩家最多 32 个上传舞蹈/64 MiB，4 个内置舞蹈不占上传配额，全库 128 MiB；8 个轮盘快捷槽只保存引用，与上传配额分开。
- **独立麦克风**：归入可选的沉浸式奏乐（Immersive Melodies）分页；生存模式竖直配方为音符盒 → 红石中继器 → 铜锭，产出 1 个麦克风。

## 安装与兼容

1. 安装 Minecraft 1.21.1、NeoForge 21.1.243（或同 21.1.x 兼容版本）和 Java 21。
2. 将 `kuso_penguin-1.0.3beta.jar` 放入客户端与服务端的 `mods/`。
3. 女仆、YSM 和沉浸式奏乐均为可选；本模组不强制安装它们。

## 已知边界

- 本次发布说明只描述已实现并审核的行为；多人同时观察、任意 YSM addon 层、游泳/骑乘/滑翔组合及各模型最终观感仍未经完整验证，不作保证。
- 女仆音乐资格依赖原生女仆任务与日程接口；仅支持已核对的 TLM 1.5.3 接口，其他版本需重新核对描述符。
