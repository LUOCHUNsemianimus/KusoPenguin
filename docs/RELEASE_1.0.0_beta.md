# 凑企鹅 / Kuso Penguin 1.0.0_beta 发行说明

## 版本信息

- 中文名：凑企鹅
- 英文名：Kuso Penguin
- 版本：1.0.0_beta
- 环境：Minecraft 1.21.1 / NeoForge 21.1.243 / Java 21
- 内部 mod id 与 Java 包名不变：`kuso_penguin` / `com.luochun.kusopenguin`

## 本版新增：独立动物唱片机舞蹈

- 新增第四个持久偏好频道 `Trigger.ANIMAL_MUSIC`，默认 `builtin:cycle`；原有三个频道的枚举顺序和存档序号不变。
- `Prefs` 新增独立的 `animalMusic`，与 `music`、`revival`、`maidMusic` 和 8 个轮盘槽互不覆盖。旧四参数构造仍可用，并按旧行为映射 `animalMusic = music`。
- 唱片机中的玩家仍用“音乐”，精确类型东方小女仆仍用“音乐/女仆音乐”；其他唱片机参与者改用**上传该唱片者**的“动物唱片机”设置，不再误用最近玩家的设置。
- 舞蹈库界面新增第四行“动物唱片机 / Animal jukebox”，tooltip 说明其使用上传者设置。布局在 1280×720 GUI 3 下采用紧凑行高，避免与底部按钮重叠。
- 舞蹈网络注册版本升到 2；客户端与服务端必须使用同一 1.0.0_beta 构建，旧客户端会被明确拒绝。
- 旧 `preferences.json`（schema 1）若没有 `animal_music`，加载时从原 `music` 迁移，保留旧存档中动物实际使用的动作；字段存在但格式非法时仍按原有严格校验拒绝，不会静默修复。新保存会写入 `animal_music`。
- 删除本人上传动作时，只清理受影响的 `animalMusic` 引用并恢复该频道默认，不重置其他频道、槽位或其他玩家设置。

## 既有已实现内容

- 企鹅效果及普通/喷溅/滞留药水、完整酿造链；保留原版头部、装备和头部装饰的视觉变形。
- 支持成年玩家、骷髅、僵尸、村民、僵尸村民、猪灵、僵尸猪灵、苦力怕、末影人、凋灵骷髅、铁傀儡、监守者，以及俯卧家族的牛、羊、猪、猫、狼、蜘蛛、洞穴蜘蛛；其他实体与幼年体保持原版。成年玩家的蹲下、骑乘、游泳和鞘翅飞行仍保留企鹅外观，其他生物的原版坐下、乘客和游泳回退不变。
- 三档企鹅网格、原版姿势映射、首次 taunt、死亡动作和飞踢。
- 自定义舞蹈库：规范 JSON、受支持的 Mixamo DAE 子集、预览、上传、所有权/配额校验、服务端权威播放。
- 音乐、复活、女仆音乐三个触发频道，K 键轮盘和 8 个可绑定快捷槽。
- 自定义唱片、可选沉浸式奏乐乐器/人声/麦克风适配、可选东方小女仆适配。

## 升级注意事项

1. **旧 Flair 动作需要重新导入。** 修复前的 Flair 导入/循环结果可能保留旧淡出或循环接缝；请在 1.0.0_beta 中重新导入源 DAE，让服务端重新生成规范动作和哈希，而不是继续使用旧条目。
2. **客户端与服务端必须同版本。** 舞蹈协议为 2；混用旧客户端会造成连接被拒绝或偏好不同步，这是有意行为。
3. 旧存档的舞蹈偏好会自动迁移动物频道；不需要手动编辑 `preferences.json`。建议升级前备份世界目录下的 `kusopenguin/dances/`。
4. `/kusopenguin` 入口、导入/选择/上传流程没有新增命令或第二套设置界面。

## 验证边界

本版发布说明描述的是已实现并经过开发检查的功能，不代表所有生物、所有 DAE/FBX、所有光影或所有多人网络环境都已验证。自定义 DAE 仍限于 30 FPS、Y_UP、已知骨架和同步 LINEAR matrix 通道的 Mixamo 子集；最终外观与多人观感以实际客户端和服务端验收为准。
